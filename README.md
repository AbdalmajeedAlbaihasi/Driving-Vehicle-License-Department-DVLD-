# Driving & Vehicle License Department (DVLD)

**Status: In Development**

## Overview

DVLD is a management system currently being developed using C# and ASP.NET Core Web API. The project focuses on managing driving license applications, users, and licensing processes through a structured backend architecture.

The goal is to apply backend development principles, relational database design, and maintainable software architecture to a practical application.

## Technologies

- C# / .NET
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- LINQ
- RESTful APIs
- Git & GitHub

## Project Scope

The system is being developed to support:

- People and user management
- Driving license applications
- License classes and licensing workflows
- Database operations using Entity Framework Core
- RESTful API endpoints and DTOs
- Business logic and input validation

Features are being implemented progressively.

## Architecture

The backend follows a layered approach to separate API endpoints, business logic, and data access responsibilities.

## Development Status

This project is currently under active development. Features, APIs, and database structures may change as development progresses.
